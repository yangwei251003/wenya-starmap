# 问芽星图 Vercel 部署说明

## 部署目标
本项目采用 Next.js App Router 架构，前端页面、后端 API、后台控制台统一部署到 Vercel，同域运行，便于答辩演示与后续维护。

## 推荐流程
1. 推送代码到 GitHub 仓库
2. 在 Vercel 中导入该仓库
3. 配置环境变量
4. 由 Vercel 自动构建并发布

## 需要配置的环境变量
- `NEXT_PUBLIC_APP_URL`
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `DATABASE_URL`
- `OPENROUTER_API_KEY`
- `OPENROUTER_MODEL`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`

## 构建命令
```bash
npm run build
```

## 本地验证
```bash
npm install
npm run build
npm run dev
```

## 部署确认点
- 首页、学习页、AI 对话页可打开
- `/api/*` 路由正常响应
- `/admin` 后台控制台可安全鉴权
- Vercel 中环境变量已完整配置
