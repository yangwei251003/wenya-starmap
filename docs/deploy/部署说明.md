# 🚀 部署到Netlify - 快速开始

## 📦 三种部署方式

### 方式1: 自动化脚本（最简单）⭐ 推荐

```powershell
# 运行部署脚本
.\quick-deploy.ps1
```

然后按照提示选择：
1. **测试构建** - 先测试项目能否正常构建
2. **Netlify CLI部署** - 自动部署到Netlify
3. **准备上传包** - 生成zip文件手动上传

### 方式2: 手动命令

```bash
# 1. 安装依赖
npm install

# 2. 测试构建
npm run build

# 3. 安装Netlify CLI
npm install -g netlify-cli

# 4. 登录Netlify
netlify login

# 5. 部署
netlify deploy --prod
```

### 方式3: GitHub自动部署（推荐用于长期维护）

```bash
# 1. 推送到GitHub
git add .
git commit -m "Ready for deployment"
git push origin main

# 2. 在Netlify网站导入GitHub仓库
# 访问 https://app.netlify.com
# 点击 "Import from Git"
# 选择你的仓库
```

## 🎯 最快部署方法（5分钟）

### 步骤1: 构建项目
```bash
npm install
npm run build
```

### 步骤2: 手动上传
1. 访问 https://app.netlify.com
2. 注册/登录账号
3. 点击 "Add new site" → "Deploy manually"
4. 拖拽整个项目文件夹到上传区域
5. 等待部署完成（约2-3分钟）

### 步骤3: 访问网站
部署完成后，Netlify会给你一个URL：
```
https://你的网站名.netlify.app
```

## 🐛 遇到问题？

### 构建失败
```bash
# 清理并重新构建
rm -rf node_modules .next
npm install
npm run build
```

### API路由不工作
检查 `next.config.js`，确保没有：
```javascript
output: 'export'  // 删除这一行
```

### 页面刷新404
确保 `netlify.toml` 存在且配置正确
