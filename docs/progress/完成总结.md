## 💡 使用技巧

### 课程学习技巧
1. **先听后读** - 点击🔊按钮听发音，再跟读
2. **重复练习** - 单词可以多次播放直到听清
3. **完成练习** - 认真完成课后练习巩固知识
4. **查看解释** - 答错了要看详细解释

### 互动练习技巧
1. **听力题** - 可以重复播放，不要着急
2. **选择题** - 先思考再选择
3. **填空题** - 注意时态和拼写
4. **口语题** - 大声朗读，培养语感

### 语音功能技巧
1. **使用Chrome或Edge浏览器** - 语音质量最好
2. **确保音量已打开** - 检查系统和浏览器音量
3. **跟读模仿** - 听的同时跟着读
4. **注意语调** - 不只是单词，还要学语调

## ❓ 常见问题

### Q1: 为什么听不到语音？
**A:** 请检查：
1. 浏览器是否支持Web Speech API（推荐Chrome/Edge）
2. 系统音量是否打开
3. 浏览器音量是否打开
4. 是否允许网站播放音频

### Q2: 课程在哪里？
**A:** 
1. 访问 http://localhost:3001/demo 快速登录
2. 点击"课程学习"卡片
3. 选择任意课程开始学习

### Q3: 如何练习听力？
**A:**
1. 访问 http://localhost:3001/quiz
2. 选择"听力练习"
3. 题目会自动播放音频
4. 可以重复播放

### Q4: 进度会保存吗？
**A:** 
- 是的！使用localStorage自动保存
- 完成的课程会标记
- 学习进度会记录
- 下次访问自动恢复

### Q5: 可以离线使用吗？
**A:**
- 语音功能可以离线（浏览器内置）
- 课程内容可以离线浏览
- AI对话需要网络连接
