# 🚀 快速启动指南

## 立即开始使用

### 1. 启动开发服务器
```bash
npm run dev
```

### 2. 打开浏览器
访问: `http://localhost:3000`

### 3. 注册/登录
- 如果是新用户，访问 `/auth/register` 注册
- 如果已有账号，访问 `/auth/login` 登录

### 4. 开始学习！

## 🎯 核心功能快速入口

### Dashboard (主页)
`http://localhost:3000/dashboard`

从这里你可以:
- 📚 开始学习（3种模式）
- 🎯 查看学习目标
- 🏆 参与每日挑战
- 🤖 获取AI建议
- 📊 查看排行榜
- ⭐ 查看成长星图

### 学习模式

#### 1. 传统学习模式
- 点击"开始学习(传统模式)"按钮
- 或直接访问: `/study`
- 特点: 经典SRS算法，简单易用

#### 2. 智能学习模式 (FSRS) ⭐ 推荐
- 点击"智能学习(FSRS)"按钮
- 或直接访问: `/study-fsrs`
- 特点: 
  - 最先进的FSRS算法
  - 智能调度复习时间
  - 记忆强度可视化
  - 键盘快捷键支持

**键盘快捷键**:
- `Space` - 翻转卡片
- `1` - 忘记了
- `2` - 困难
- `3` - 良好
- `4` - 简单
- `Esc` - 返回

#### 3. 增强版学习
- 访问: `/study-v2`
- 特点: 可配置学习计划，多组学习

## 🔧 故障排除

### 问题: 智能学习一直加载
**解决**: 
1. 刷新页面 (F5)
2. 清除浏览器缓存
3. 重启开发服务器

### 问题: 按钮点击无反应
**解决**:
1. 打开浏览器控制台查看错误
2. 硬刷新页面 (Ctrl+Shift+R)
3. 检查是否有JavaScript错误

### 问题: 数据不保存
**解决**:
1. 检查是否在隐私模式
2. 确保浏览器允许localStorage
3. 清除旧数据: `localStorage.clear()`
