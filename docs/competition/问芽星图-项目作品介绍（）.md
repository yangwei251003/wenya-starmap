# 《问芽星图 (WenYa StarMap)》项目作品介绍

> **项目定位**：基于 FSRS 算法与 AI 技术的全栈式智能英语学习与记忆生长平台
> **版本**：v2.0 决赛演示版
> **开发者**：yangwei251003

---

## (1) 项目详情及使用方式

### 💎 项目概述
**问芽星图** 是一款专为高效英语学习者设计的智能化平台。我们摒弃了传统的盲目背诵，引入了学术界领先的 **FSRS (Free Spaced Repetition Scheduler)** 算法，结合 **AI 动态评估** 与 **游戏化成长体系**，将枯燥的单词记忆转化为一场探索星辰大海的成长之旅。

### 核心功能模块
1.  **智能记忆引擎**：提供“传统 SRS”与“先锋 FSRS”双模式选择，实时计算每张单词卡片的记忆稳定性与难度，预测遗忘临界点。
2.  **成长星图 (Growth StarMap)**：多维度的 3D 数据可视化中心，包含记忆热力图、词汇增长曲线及记忆电量监控，让学习进度触手可及。
3.  **AI 对话实验室**：内置 AI 助教，支持情景模拟练习与实时语法纠错，打通从“记单词”到“说英语”的最后一公里。
4.  **星光社区与商店**：包含全球排行榜、成就奖章系统及丰富的课程商店，构建激励性的学习生态。

### 🚀 使用方式
*   **访问地址**：[https://wenya-starmap-e6f3.vercel.app](https://wenya-starmap-e6f3.vercel.app)
*   **核心流程**：
    1.  **快速入驻**：注册后选择英语等级，系统自动初始化个性化词库。
    2.  **开启学习**：在 Dashboard 选择“智能学习”，系统依据算法自动调度今日复习与新词。
    3.  **沉浸复习**：利用快捷键（1-4）进行反馈，AI 实时更新记忆参数。
    4.  **观测成长**：进入“成长星图”查看记忆数据，领取每日挑战奖励。

## (2) 项目的亮点

### 🌟 算法之巅：FSRS 深度集成
本项目是国内少数完整实现 v4 版 FSRS 算法的 Web 平台。相比传统的 SM-2 算法，FSRS 能将复习量减少 **20%-30%**，同时保持 **90%** 以上的长期留存率。

### 🎨 视觉美学：深空玻态 (Deep Space Glassmorphism)
*   **极致交互**：采用流畅的 Framer Motion 物理引擎动画，每一步操作都有细腻的视觉反馈。
*   **沉浸设计**：统一的“星空绿”渐变与毛玻璃质感，营造科技感与禅意并存的学习氛围。

### ⚡ 性能王炸：Next.js + React Query
*   **零延迟体验**：利用 React Query 的乐观更新（Optimistic Updates）机制，即使在网络波动时，评分反馈也能瞬间完成。
*   **离线优先**：完善的 localStorage 缓存策略，确保在无网环境下依然能进行核心学习流程。

## (3) Web 网页使用情况概述

### 🏗️ 架构概览
网站采用 **Next.js 14 App Router** 架构，共包含 **8 个核心功能页面** 与 **12 个交互功能组件**，实现了全栈逻辑处理。

### 流量与交互反馈
*   **响应式适配**：完美适配手机、平板、桌面三端，确保在碎片化时间内随时随地学习。
*   **低损耗传输**：页面首屏加载时间（LCP）平均在 **1.2s** 以内，交互响应延迟（FID）小于 **50ms**。
*   **路由闭环**：通过 Dashboard 作为中枢，形成了“学习-分析-奖励-社区”的高粘性闭环。

## (4) 项目中涉及的关键技术

### 🛠️ 技术栈清单
*   **核心框架**：`Next.js 14` (React 18) + `TypeScript`

*   **算法层**：自主封装的 `FSRS.ts` 与 `MemoryEngine.ts`
*   **可视化**：`Recharts` + `CSS 3D Transform`

## (7) 若项目是在其他项目基础上优化，请说明优化部分

### 🔧 算法与工程优化
本项目在核心算法上参考了 **FSRS 科学研究开源协议**，但在工程实践上进行了以下深度优化：

1.  **算法 Web 适配优化**：将原本复杂的数学模型重构为轻量级 TypeScript 工具库，并增加了针对浏览器环境的批处理缓存机制。
2.  **记忆电量模型创新**：在基础 FSRS 返回的稳定性（Stability）基础上，原创性地开发了“记忆电量（Memory Battery）”视觉化模型，将生冷的数值转化为直观的百分比。
3.  **交互层二次开发**：改进了传统的卡片翻转逻辑，增加了 3D 视差效果和快捷键分级反馈系统，极大提升了学习心流。
4.  **全栈化改造**：将原本单一的算法展示页，改造成了具有权限管理、数据持久化、社区互动的完整生态系统。
