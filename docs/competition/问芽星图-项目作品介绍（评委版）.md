# 《问芽星图 (WenYa StarMap)》项目作品介绍（评委版）

> **赛道定位**：智慧教育 Web 开发赛道
> **项目形态**：前后端一体化全栈应用
> **部署方式**：GitHub 持续集成 + Vercel 自动部署

## 一句话介绍
问芽星图是一款面向大众的 AI 英语学习平台，用动态星图、语音陪伴、智能复习与后台运维控制台，把“学英语”做成一条看得见路径的成长体验。

## 项目亮点
1. **语言星图**：把课程、单词、成就和成长轨迹重构为可点亮的星座路径，学习结果一眼可见。
2. **NovaSprout 语音助手**：AI 回复结合 Web Audio 节奏分析，形成会“呼吸”的星光种子视觉。
3. **智能复习系统**：围绕 FSRS / SRS 记忆调度，让复习时机更科学，减少无效重复。
4. **后台控制台**：内置数据库与服务运维入口，可查看用户、订单、交易、订阅、学习日志与服务健康。
5. **全站一致的科技浪漫主义视觉**：深空底色、薄荷绿毛玻璃、流光动效和克制交互统一到所有核心页面。

## 核心功能
- 登录注册与用户分层
- AI 对话与语音陪练
- 今日学习路径与个性化推荐
- 词汇学习、课程购买、星币系统
- 成长星图与学习成就可视化
- 后台管理控制台与数据库健康查看

## 技术架构
- **前端**：Next.js 14 + React 18 + TypeScript
- **样式**：Tailwind CSS + Framer Motion
- **后端**：Next.js API Routes
- **数据层**：Supabase
- **部署**：Vercel

## 部署说明
项目采用同仓一体化部署：
- 页面、API、后台控制台全部部署到 Vercel
- 前后端同域，便于鉴权、调试和演示
- 持续提交 GitHub 后自动触发 Vercel 构建

## 答辩表达建议
评委看到的不是一个“Demo”，而是一个完整的教育产品闭环：
- 用户进入后先获得明确学习路径
- 学习中通过星图和语音反馈持续被鼓励
- 学习后能看到成长和复习建议
- 管理端能看到系统健康、数据状态和业务链路

## 结语
问芽星图希望表达的不是“多做了几个页面”，而是把英语学习从任务变成路径，把路径变成星图，把成长变成可持续的体验。
