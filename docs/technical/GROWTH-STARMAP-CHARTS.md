# 成长星图可视化图表系统

## 概述
成长星图现在包含三个核心可视化图表，帮助用户全面了解自己的学习情况。

## 三大图表

### 1. 记忆遗忘曲线（电池电量风格）
- **位置**: 页面顶部，全宽显示
- **功能**: 展示最近学习的10个单词的记忆保持率
- **设计**: 
  - 使用绿色线条（#22C55E）表示记忆曲线
  - Y轴范围 0-100%，类似电池电量显示
  - 显示平均记忆率、需要复习数量、记忆牢固数量
- **数据来源**: localStorage 中的用户单词记录

### 2. 词汇累积堆叠图
- **位置**: 中间左侧
- **功能**: 展示过去30天的词汇累积趋势
- **设计**:
  - 使用堆叠面积图（Area Chart）
  - 绿色区域（#22C55E）表示已掌握单词
  - 黄色区域（#F59E0B）表示学习中单词
  - 清晰区分熟词和生词
- **数据来源**: 历史学习记录

### 3. 学习热力图（GitHub 风格）
- **位置**: 中间右侧
- **功能**: 展示过去365天的学习活动
- **设计**:
  - 类似 GitHub 贡献图的热力图
  - 5个等级的绿色深浅（#1F2937 到 #059669）
  - 显示活跃天数、周平均、单日最高
  - 鼠标悬停显示具体日期和单词数
- **数据来源**: 每日学习会话记录

## 配色方案（星空绿主题）

```css
主色调:
- 深绿色: #22C55E (sprout-400)
- 星光黄: #FACC15 (star-400)
- 深空蓝: #1F2937 (cosmos-800)

图表配色:
- 已掌握: #22C55E (绿色)
- 学习中: #F59E0B (黄色)
- 需复习: #F97316 (橙色)
- 背景: #1F2937 (深灰)
- 网格: #374151 (中灰)
- 文字: #9CA3AF (浅灰)
```

## 技术实现

### 依赖库
- **Recharts**: 用于折线图和面积图
- **自定义热力图**: 使用 CSS Grid 实现

### 数据流
1. 从 localStorage 读取用户学习数据
2. 处理和聚合数据
3. 生成图表所需的数据格式
4. 使用 Recharts 渲染图表

### 响应式设计
- 移动端: 图表垂直堆叠
- 平板: 2列布局
- 桌面: 优化的宽屏布局

## 访问路径

1. **从 Dashboard 进入**:
   - 点击背单词卡片下方的"查看成长星图"按钮
   - 或点击快捷操作区的"成长星图"卡片

2. **直接访问**:
   - URL: `/growth-starmap`

## 数据更新

图表数据会在以下情况更新:
- 页面加载时自动读取最新数据
- 点击刷新按钮手动更新
- 完成学习后返回页面时自动更新

## 特色功能

1. **实时数据**: 所有数据来自真实的学习记录
2. **智能分析**: 自动计算记忆率、学习趋势等指标
3. **交互体验**: 鼠标悬停显示详细信息
4. **美观设计**: 符合整体"星空绿"主题风格
5. **性能优化**: 使用 ResponsiveContainer 自适应容器大小
