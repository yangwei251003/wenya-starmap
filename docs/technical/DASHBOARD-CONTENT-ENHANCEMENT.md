# Dashboard 内容增强 - 新增模块

## 概述
为了让dashboard页面内容更加充实，我们新增了两个重要的学习模块，填充了用户提到的圆圈区域，让页面看起来更完整和功能丰富。

## 新增模块

### 1. 学习目标追踪器 (StudyGoals.tsx)
**位置**: 左侧圆圈区域
**功能特点**:
- 📊 **多时间维度**: 支持每日、每周、每月目标切换
- 🎯 **智能目标**: 基于用户学习数据自动生成个性化目标
- 📈 **进度可视化**: 环形进度图和进度条双重展示
- ✅ **完成状态**: 实时跟踪目标完成情况

**目标类型**:
- 每日目标: 单词学习量、准确率、连续学习
- 每周目标: 周学习总量、学习天数
- 月度目标: 掌握词汇数、连续学习天数

**视觉设计**:
- 星空绿主题配色
- 动态进度条和环形图表
- 完成状态的视觉反馈
- 响应式布局适配

### 2. 每日挑战系统 (DailyChallenge.tsx)
**位置**: 右侧圆圈区域
**功能特点**:
- 🚀 **多样化挑战**: 速度、准确率、连续性、学习量等不同类型
- 🏆 **奖励机制**: 星币、经验值、成就徽章三重奖励
- ⏰ **时间限制**: 部分挑战有时间限制增加紧迫感
- 🎮 **游戏化**: 难度等级、进度追踪、成就系统

**挑战类型**:
- ⚡ 速度大师: 限时学习挑战
- 🎯 精准射手: 高准确率挑战
- 🔥 连击战士: 连续学习挑战
- 📚 学习狂魔: 大量学习挑战
- 🌟 周末特训: 特殊时间挑战

**奖励系统**:
- 星币奖励: 50-150不等
- 经验值: 100-300不等
- 成就徽章: 特殊称号和标识

## 页面布局更新


## 数据流集成

### 学习统计数据
所有新模块都使用统一的学习统计数据:
```typescript
studyStats: {
  streak: number        // 连续学习天数
  todayCompleted: number // 今日完成单词数
  accuracy: number      // 学习准确率
  totalMastered: number // 总掌握单词数
}
```

### 本地存储
- 挑战完成状态: `wenya_challenges_{userId}_{date}`
- 学习会话数据: `wenya_study_session_{userId}_{date}`
- 用户单词数据: `wenya_user_words_{userId}`
