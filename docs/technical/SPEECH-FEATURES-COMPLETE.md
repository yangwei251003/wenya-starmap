# 🔊 语音功能完整指南

## ✅ 已实现的语音功能

### 1. **课程学习中的语音** (`/lesson/[id]`)

#### 📖 词汇学习
- **单词发音** - 点击单词旁的🔊按钮
  - 慢速朗读一次
  - 短暂停顿
  - 正常速度再读一次

- **例句朗读** - 点击例句旁的🔊按钮
  - 完整朗读例句
  - 正常语速
  - 理解句子语调

#### 💬 对话练习
- **对话朗读** - 每句对话都有🔊按钮
  - 模拟真实对话
  - 分角色朗读
  - 学习语音语调

### 2. **互动练习中的语音** (`/quiz`)

#### 🎧 听力练习
- **自动播放** - 进入听力题自动播放
- **重复播放** - 点击🔊按钮重复听
- **停止播放** - 再次点击停止
- **刷新按钮** - 重新开始播放

#### 🎤 口语练习
- 提示大声朗读
- 练习发音和流利度

## 🎯 使用方法

### 课程学习语音

1. **进入课程详情**
   ```
   Dashboard → 课程学习 → 选择课程 → 开始学习
   ```

2. **词汇学习步骤**
   - 到达"核心词汇"步骤
   - 看到单词卡片
   - 点击单词旁的🔊按钮
   - 听单词发音（慢+快）
   - 点击例句旁的🔊按钮
   - 听完整例句

3. **对话练习步骤**
   - 到达"对话练习"步骤
   - 看到对话内容
   - 点击每句话旁的🔊按钮
   - 听真实对话发音

### 互动练习语音

1. **听力练习**
   ```
   Dashboard → 互动练习 → 选择"听力练习"
   ```

2. **答题流程**
   - 题目自动播放音频
   - 点击🔊按钮重复播放
   - 点击🔄按钮重新播放
   - 听清楚后选择答案

## 🔧 技术实现

### Web Speech API
使用浏览器内置的语音合成API：
- ✅ **完全免费** - 无需API密钥
- ✅ **即开即用** - 无需配置
- ✅ **离线可用** - 不依赖网络
- ✅ **多语言支持** - 自动选择英语语音

### 语音参数

#### 单词发音
```typescript
{
  rate: 0.7,    // 慢速（70%）
  pitch: 1.1,   // 音调稍高
  lang: 'en-US' // 美式英语

```

#### 例句朗读

## 🔍 常见问题

### Q: 为什么没有声音？
A: 检查以下几点：
1. 浏览器音量是否打开
2. 系统音量是否打开
3. 浏览器是否支持Web Speech API
4. 是否允许网站播放音频

### Q: 发音不标准怎么办？
A: 
1. 浏览器会自动选择最佳英语语音
2. Chrome和Edge的语音质量最好
3. 可以在系统设置中安装更多语音包

### Q: 可以调整语速吗？
A: 
- 当前设置为学习优化速度（80%）
- 单词发音更慢（70%）
- 未来可以添加速度调节功能

### Q: 支持离线使用吗？
A: 
- 是的！Web Speech API可以离线工作
- 前提是系统已安装英语语音包
- 首次使用可能需要下载语音数据

### Q: 听力题为什么自动播放？
A: 
- 模拟真实听力考试
- 培养即时理解能力
- 可以点击按钮重复播放
