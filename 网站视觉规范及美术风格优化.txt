🌌 一、 视觉风格定义：科技浪漫主义（Sci-Fi Romanticism）
大众用户讨厌沉闷的“蓝色教辅风”，也讨厌过于硬核的“黑客暗黑风”。我们要走的是类似 Duolingo（多邻国）的趣味性与 Linear / Apple 官网的高级感的结合体。

色彩画布（The Palette）：

夜空底色（问）：深邃的极暗蓝灰色（如 #0B0F19），作为整个宇宙星图的背景，代表未知与探索。

萌芽生命绿（芽）：高饱和度的荧光薄荷绿（如 #10B981 或 #00F5A0），用于代表用户的成长、正确的回答、以及新激活的技能。

星光金/荧光蓝（星、图）：代表目标与路径的连线。

质感与材质（Glassmorphism）：

大量采用毛玻璃质感（backdrop-blur）的悬浮卡片。让用户感觉所有的学习模块都像悬浮在星空中的全息投影面板。

🎨 二、 核心页面美化与“主题”深度融合方案
你要让用户每次点击、每次通关，都感觉自己是在“点亮宇宙”，而不是在刷题。

1. 首页 / 仪表盘：从“课程列表”到“个性化语言星图”
彻底干掉：传统的“第一章、第二章”列表。

重塑为【星图导航（The Star-Map）】：

核心视觉是一个由 CSS/SVG Canvas 渲染的动态星系图。每一个星座代表一个语境主题（如：商务社交座、日常口语座、学术前沿座）。

星座里的每一颗星星代表一个关卡（单词或听力）。

未解锁时：星星呈黯淡的灰蓝色休眠状态（好奇的种子）。

通关后：星星爆发出耀眼的荧光绿，并向下一颗星星发射出一道粒子连线（绘制路径）。

2. AI 口语助教：动态数字伴侣【星芽 · NovaSprout】
彻底干掉：一个光秃秃的聊天框+发送按钮。

重塑为【全息陪伴流】：

界面中央是一个纯 CSS/SVG 绘制的星光种子球体。

交互动画：

当用户说话时，球体向内收缩、凝聚能量；

当 AI（Gemma 4）思考时，球体表面出现如同流星般的流光打转；

当 AI 说话（语音播放）时，利用前端 Web Audio API 实时获取音频的振幅，让这个球体随着声音的节奏像水母或萌芽一样有节奏地向外扩散音波涟漪。

3. 词汇与资源学习：【萌芽采集器】
重塑交互：

调用外部词典 API 获取到单词后，不要直接拍在屏幕上。

设计一个“破土而出”的卡片翻转特效。用户每记住一个单词，就相当于收集到了一片“光合叶片”，可以用来滋养自己的星图。

⚡ 三、 顶级交互（UX）的商业化细节：细节决定成败
大众用户对产品的黏性往往来自于极其微小的爽感。

丝滑的微交互（Micro-interactions）：

使用 Framer Motion（如果你用 React）或 GSAP（通用）。按钮悬浮时不要生硬地变色，而是要带有引力吸附效果（鼠标靠近时按钮微微向鼠标位移）和星光溢出渐变。

声音美学（Audio Feedback）：

用户点击通关或点亮星星时，触发一个空灵、清脆的“星体共鸣音效”（类似 Sci-Fi 乐器或清脆的水滴声），给用户极强的多级正向反馈。

商业化付费点（Stripe 触点）的高级融合：

当用户的 AI 免费通话额度用尽时，千万不要弹出粗暴的“充值弹窗”。

弹出一个充满仪式感的浮窗：“当前星体能量已耗尽。点击注入‘星图燃料’（充值/订阅），让 NovaSprout 保持长明陪伴。”点击后拉起丝滑的 Stripe 结账飞入动画。
1. 🌌 连线星图与粒子星空必备：Canvas / SVG Animation Expert
增强方向：实现你要求的“动态语言星图”以及“通关后星星闪烁连线”的粒子效果。

让 Codex 调用的核心库文档（用 Fetch 抓取）：

Three.js / React Three Fiber (R3F)：如果想做 3D 悬浮旋转的宇宙星空球。

Pixi.JS / Canvas API：最适合用来做高性能、丝滑的 2D 动态星座连线网格。

对 Codex 说：“请使用你的 Fetch 工具去抓取并参考最新的 Pixi.JS 或现代 HTML5 Canvas 连线粒子特效代码，为我设计星图主页。”

2. ⚡ 丝滑微交互与物理吸附感：Framer Motion / GSAP Hub
增强方向：按钮悬浮时的“星光溢出”、卡片翻转时“破土而出”的动态生命感，以及极具高级感的页面入场淡入动效。

让 Codex 调用的核心库文档：

Framer Motion（如果你用的框架是 React/Next.js，这是苹果级动效的绝对底座）。

GSAP (GreenSock)（如果是通用的 Vue/HTML，这是全球最顶级的工业级动画库）。

对 Codex 说：“请调用你的内置网络检索（Browser/Fetch）查阅 Framer Motion 的手势吸引（Hover Gravity）与动态流光边框（Glow Borders）实现方式，加强我全站按钮的艺术性。”

3. 🎙️ 语音律动与图形可视化：Web Audio API / SVG Morphing
增强方向：让你的 AI 助手“星芽（NovaSprout）”能够随着 SiliconFlow 返回的音频高低起伏，像活过来的生命一样有节奏地缩放、变形、散发涟漪。

让 Codex 调用的核心技能/文档：

Web Audio API (AnalyserNode)：实时捕捉和解析音频频率数据。

Lottie-Web / SVG Morphing：用代码去实时扭曲 SVG 的路径，达成极具科技浪漫主义的平滑水母/发芽律动。

对 Codex 说：“请用思维链（Sequential Thinking）深度构思如何利用 Web Audio API 获取音频振幅，并将其数值映射（Map）到前端 SVG Path 变形动画上，打造‘星芽’的说话律动效果。”

4. 🎨 现代潮流色彩与玻璃拟态：Tailwind CSS Modern Presets
增强方向：无需手写成千上万行复杂的 CSS。利用现代毛玻璃（Glassmorphism）和渐变发光，快速堆砌出大众极度喜欢的 Linear（硅谷最高审美代表）风格。

让 Codex 调用的核心技能/文档：

Tailwind CSS v4 (或当前最新版) 文档。

Shadcn UI / Magic UI / Aceternity UI（目前全球前端圈最火的、自带满分艺术感的开源组件库，专门用来写星空背景、流光卡片）。

对 Codex 说：“请检索 Aceternity UI 或 Magic UI 的开源艺术组件设计，直接套用其‘Sparkles’（星星闪烁背景）和‘Bento Grid’（精美便当格排版）的 Tailwind 实现方式来优化我们的页面布局。”
